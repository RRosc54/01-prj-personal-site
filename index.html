Intel Sustainability Project

This first project showcases my ability to create a visually appealing and informative website for Intel's Sustainability timeline. This site features the use of CSS, HTML, and Bootstrap to create a clean and modern design, with easy navigation and clear information about Intel's goals and accomplishments over the years.

Intel Summit Checkin

This project uses Javascript, HTML, and CSS to create a check in tracker that stores the users that check in and creates a list that keeps that calculates the number of people per team. Once the counter reaches 50 the checkin is closed and the team with the most checkins is displayed. This project was created to simulate a checkin for an event that Intel was hosting.

Charity Water Game

This game was created to raise awareness for Charity: Water. The interactive game was created using HTML, CSS, and JavaScript to create a fun and engaging experience for users. The game features a simple yet effective design, with clear instructions with different difficulties and a scoring system that encourages players to keep playing and learn more about the cause.

NASA Space Explorer

This project explores space-themed web design and interactive content, showcasing a creative way to present information through a polished user experience. Using a NASA API to pull in data about space missions, this project demonstrates the ability to work with APIs and create a visually appealing and informative website.

L'Oréal Chatbot

This project highlights an interactive chatbot experience with a polished design and engaging conversational flow. It demonstrates creative web design and user-friendly interaction concepts. This project was created to simulate a Chatbot for L'Oreal and uses a generated API from OpenAI and only answers questions about the products the company offers to consumers.

L'Oréal Routine Builder

An AI-powered beauty routine builder that allows users to browse and save L’Oréal products, generate personalized routines, and ask contextual follow-up questions through an integrated chatbot. Built with JavaScript, JSON, localStorage, the OpenAI API, and Cloudflare Workers, the project highlights secure API integration, prompt engineering, responsive design, and user-focused front-end development.
